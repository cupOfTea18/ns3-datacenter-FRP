# 编译命令
cd /home/shemuping/newCode/ns3-FRP/simulator/ns-3.39

./configure.sh  
./ns3 build 
./ns3 run xxx

configure.sh 中设置选项，  
--build-profile=optimized 发布版 + 针对当前 CPU 的优化 ，测试性能时用这个  
--build-profile=debug   调试版，开启断言和日志，带调试信息

开启日志：
./ns3 configure --enable-logs
关闭： ./ns3 configure --disable-logs  关闭提升性能
