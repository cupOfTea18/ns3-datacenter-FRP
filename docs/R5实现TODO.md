# R5 实现任务

依据：[方案](R5设计方案一.md)、[实现设计](R5代码设计与实现.md)，包括实现设计末尾的 D1–D6 决策。保留工作区已有修改，不调整主机 DCQCN 算法与恢复参数。

## 任务及验收条件

- [x] 1. 地址：每 Leaf 独立 `/24`、每主机一个实际 IP；地址映射、精确路由、PFC 和统计一致。
- [x] 2. RDMA 身份：端点分配和交换 QPN，目的 QPN 真实序列化；网关键仅含源 IP、目的 IP、目的 QPN。
- [x] 3. 源 QP 登记：运行时登记、确认与有限重试；未确认时不得主动 CNP；登记不创建数据控制状态。
- [x] 4. 动态发现与执行：网关空表启动，A/B 首包独立建表；逐流四帧满桶，零速率保留余额并停发，资源不足明确处理。
- [x] 5. 反馈：独立流/资源身份、B 主动反馈、会话与代际、序号去重及超时；B 保持实际 PG/FIFO，仅观测；运行时测量时延。
- [x] 6. 预测与分配：实际发送历史 + 近期供给预测，终点 `t + d_f + d_b`；记录途中峰值；逐流上限和份额分离，联合共享资源预算。
- [x] 7. 反压：实际 A 缓存压力、定向贡献流、响应等待；保留原生 CE/CNP/PFC。
- [x] 8. 可观测性：新协议/日志版本、有效参数、边界和未实现项；更新分析与审计，禁止按旧组桶语义解释。
- [x] 9. 验证：构建、机制回归、不同 Leaf/方向与不同 QPN 的小规模闭合验证，检查字节、令牌、丢弃、队列/MMU 与源文件差异。

## 范围说明

用户已确认按文末决策实施：D4 本轮不新增共享启动/恢复许可和额外风险收紧迭代。D7（等待缓存/MMU）、D8（跨代计数核销）、D9（完整资源/老化参数）暂缓。未核销状态保留；各池仍有硬上限，资源不足明确拒绝并计数，不旁路整形、不承诺完整等待/回收协议。

性能比较和大范围实验不作为本轮验收要求。所有验证记录必须注明实际版本、配置与统计口径。
